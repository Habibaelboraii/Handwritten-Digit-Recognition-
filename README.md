# Handwritten Digit Recognition using Deep Learning (CNN)

## Overview

This project implements a Convolutional Neural Network (CNN) for handwritten digit classification using the MNIST dataset.

## Features

* Data preprocessing and normalization
* Image reshaping and one-hot encoding
* CNN model development using TensorFlow/Keras
* Model optimization using Batch Normalization and Dropout
* Performance comparison before and after optimization
* Confusion Matrix and Classification Report
* Interactive GUI for digit prediction using Tkinter

## Technologies

* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib
* Seaborn
* Tkinter

## Dataset

MNIST Handwritten Digits Dataset

## Results

The optimized CNN model achieved significantly higher classification accuracy compared to the baseline model while reducing overfitting through regularization techniques.
